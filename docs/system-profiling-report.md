方案 C 實飛的停頓不是 Virtual Stick 發送失敗。影像、Flight Log 與失敗影格重播顯示，黑色膠帶通過紙板接縫時，接縫會暫時與膠帶成為同一個二值連通區；舊中心線演算法只以幾何長度選終點，可能轉入較長但較窄的紙板接縫。即使中心線仍正確，接縫也會遮住少量板色取樣：實飛失敗影格仍有 45–46 組有效雙側樣本、雙側相容率 0.96–0.98、與已學習板色距離 1.3–3.1，但取樣覆蓋率 0.68–0.70 落在原本 0.70 的硬門檻附近。粗略地板遮罩也曾降至 0.078–0.102，低於原本追蹤中門檻 0.12。
